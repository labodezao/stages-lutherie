# Guide de Contribution / Contributing Guide

Merci de votre intérêt pour améliorer le projet stages-lutherie ! / Thank you for your interest in improving the stages-lutherie project!

## 🌍 Langues / Languages

Ce projet est bilingue français/anglais. Toute contribution doit maintenir cette parité.

This project is bilingual French/English. All contributions must maintain this parity.

## 📝 Comment contribuer / How to Contribute

### 1. Documentation

Si vous souhaitez améliorer la documentation :

- Vérifiez que vos modifications sont cohérentes dans les deux langues
- Respectez le format Markdown existant
- Ajoutez des descriptions alternatives (alt text) descriptives pour toutes les images

If you want to improve documentation:

- Ensure your changes are consistent in both languages
- Respect the existing Markdown format
- Add descriptive alt text for all images

### 2. Images

- **Format recommandé** : JPG ou PNG (pas de HEIC)
- **Taille** : Optimisées pour le web (< 3 MB par image)
- **Nommage** : Utilisez des tirets au lieu d'espaces (`mon-image.jpg` pas `mon image.jpg`)
- **Alt text** : Toujours ajouter une description alternative descriptive

- **Recommended format**: JPG or PNG (no HEIC)
- **Size**: Optimized for web (< 3 MB per image)
- **Naming**: Use hyphens instead of spaces (`my-image.jpg` not `my image.jpg`)
- **Alt text**: Always add descriptive alternative text

### 3. Conventions de nommage / Naming Conventions

- Fichiers français : `-fr.md` (ex: `guide-stagiaires-fr.md`)
- Fichiers anglais : `-en.md` (ex: `guide-stagiaires-en.md`)
- Images : minuscules avec tirets (ex: `jour-05-soufflets.jpg`)

- French files: `-fr.md` (e.g., `guide-stagiaires-fr.md`)
- English files: `-en.md` (e.g., `guide-stagiaires-en.md`)
- Images: lowercase with hyphens (e.g., `day-05-bellows.jpg`)

Vérifiez que :

- [ ] Les liens fonctionnent
- [ ] Les images s'affichent correctement
- [ ] Le texte est exempt de fautes d'orthographe
- [ ] Les modifications sont présentes dans les deux langues (FR et EN)
- [ ] Le format Markdown est valide

Check that:

- [ ] Links work
- [ ] Images display correctly
- [ ] Text is free of spelling errors
- [ ] Changes are present in both languages (FR and EN)

## 📋 Pull Requests

1. Forkez le projet / Fork the project
2. Créez une branche pour votre fonctionnalité / Create a branch for your feature

   ```bash
   git checkout -b amelioration/ma-feature
   ```

3. Committez vos changements / Commit your changes

   ```bash
   git commit -m "Ajout de [description]"
   ```

4. Poussez vers la branche / Push to the branch

   ```bash
   git push origin amelioration/ma-feature
   ```

5. Ouvrez une Pull Request / Open a Pull Request

## ⚠️ Ce qu'il ne faut PAS faire / What NOT to Do

- ❌ Ne commitez pas de fichiers système (desktop.ini, .DS_Store, Thumbs.db)
- ❌ Ne commitez pas de fichiers HEIC (utilisez JPG ou PNG)
- ❌ Ne modifiez pas les informations de contact sans autorisation
- ❌ Ne commitez pas de fichiers très volumineux (> 5 MB)

- ❌ Don't commit system files (desktop.ini, .DS_Store, Thumbs.db)
