## 🎯 Plan d'action / Action Plan

### Étape 1 – Poster dans les groupes Facebook (semaine 1)

1. Rejoindre chaque groupe listé ci-dessus
2. Poster le visuel Facebook (1200×630) avec le texte d'accroche
3. Créer un événement Facebook pour chaque session (avril + octobre)

### Étape 2 – Forums spécialisés (semaine 1-2)

1. Créer un compte sur Melodeon.net, Accordionists.info, Reddit
2. Poster dans les sections appropriées (Events, Workshops, Makers)
3. Inclure le lien YouTube + lien d'inscription

### Étape 3 – Contacter les associations (semaine 2-3)

1. Envoyer l'email (version `visuel-stage-email.html`) à chaque association
2. Demander un relai dans leur newsletter / tableau d'affichage
3. Proposer un échange de visibilité (mention sur le site du stage)

### Étape 4 – Instagram (continu)

1. Poster le visuel Instagram (1080×1080) + story (1080×1920)
2. Utiliser tous les hashtags listés ci-dessus
3. Taguer les comptes makers/communautés
4. Poster des stories régulières (behind the scenes, témoignages)

### Étape 5 – Relances (semaine 4+)

1. Reposter dans les groupes Facebook 2 semaines avant chaque session
2. Poster des témoignages d'anciens stagiaires
3. Partager la vidéo YouTube dans chaque communauté
